# Phase 7-Plus: 增量 PRD — 32 占位符页面补全

> **文档版本**: v1.0
> **撰写日期**: 2026-06-30
> **撰写人**: 产品经理 许清楚(Xu)
> **阶段**: Phase 7-Plus — 增量迭代(基于 Phase 7 UI Design + Phase 8 P0 完整实现)
> **前置输入**: Phase 2 PRD / Phase 4 架构 / Phase 6 API / Phase 7 UI Design
> **覆盖范围**: 16 个 P1 扩展业务页面 + 6 个 P2 支撑业务页面 + 5 个 Dashboard 页面 + 5 个 System 管理页面(共 32 页)

---

## 1. 产品目标

1. **补齐制造业 WMS 业务闭环**:本次迭代实现调拨 / 盘点 / 线边仓 / 生产协同 / 条码标签五大扩展业务模块,从"收/存/发"核心扩展到"调/盘/产"完整业务链条。
2. **强化运营管理能力**:通过工作流 / 规则引擎 / 通知管理三大支撑模块,为业务模块提供流程编排、规则适配、消息触达能力。
3. **提供数据可视化与系统治理入口**:5 个 Dashboard 页面提供决策支持,5 个 System 页面提供基础数据治理(用户/角色/权限/组织/设置)。

> **复用原则**:严格遵循 P0 已确立的 18 个 Wms 通用组件 + `WmsSearch + WmsTable + WmsStatusTag` 三件套列表页模式 + `Tabs(基本信息/明细/时间线)` 详情页模式。所有 32 页应保持视觉/交互一致,不再引入新的设计系统变量。

## 5. 关键交互流程

### 5.1 调拨审批流(P0-TF-02)
```
创建(Draft) → [提交审批] → 审批中(Pending)
                              ↓
                          审批人通过
                              ↓
                          审批通过(Approved)
                              ↓
                    [源仓出库确认] → 出库中(Outbounding)
                              ↓
                    [源仓确认完成] → 在途(InTransit)
                              ↓
                    [目标仓入库确认] → 入库中(Inbounding)
                              ↓
                    [目标仓确认完成] → 已完成(Completed)
```
- 详情页 `WmsSteps` 6 步,当前态高亮(蓝),已完成态绿
- 详情页 `WmsTimeline` 记录每个节点操作人/时间/备注
- 操作按钮根据当前状态动态显示(草稿态显示[编辑/提交/删除],已完成态所有按钮禁用)
- 列表 SignalR 推送:状态变更时,对应行闪烁一次

### 5.2 盘点盲盘模式(P0-CC-02)
```
进入执行页 → 切换[盲盘模式]开关
   ├─ ON: 不显示账面数,只显示物料编码/库位/实盘数量输入框
   │     差异在[提交]后才计算
   └─ OFF: 显示账面数 vs 实盘数,实时差异(正/0/负)
              差异 = 实盘 - 账面
              差异绝对值 > 阈值 → 红色高亮
```
- 阈值从系统设置读取,默认 5%(可配置)
- 逐行确认:每行单独[确认]按钮,确认后该行变灰不可编辑
- 批量确认:勾选多行 → [批量确认] 弹窗输入差异原因
- [全部完成] 按钮:所有行确认后解锁,触发差异处理页跳转

### 5.3 线边仓补料触发(P0-LS-02 / P0-LS-03)
```
定时刷新(30s) / SignalR 推送
        ↓
工位库存 < 最小值
        ↓
看板卡片添加 .blink 红色闪烁 CSS 动画(1s 周期)
        ↓
[触发补料] 按钮弹出弹窗:
  - 物料(预填)
  - 建议补料数量 = 最大值 - 当前库存
  - 目标库位(默认该工位线边仓)
  - 优先级(紧急/高/普通)
  [确认] → 调用 triggerReplenishment API
        ↓
跳转到补料任务页 / 在当前页追加新任务
```
- 看板页右上角实时显示"待补料工位数: N" 红色徽章
- 补料任务页按优先级 + 创建时间倒序排列

### 5.4 看板实时刷新(P0-LS-02 增强)
- 初次加载:`getKanbanData(stationId?)` → 渲染卡片
- 实时刷新:SignalR 订阅 `LineSideHub` 事件 `InventoryChanged` → 更新对应卡片(el-progress 动画过渡)
- 自动重连:SignalR 断开时,`WmsSignalRIndicator` 显示红色,自动重连 3 次,失败后回退到 30s 轮询

### 5.5 Dashboard 时间范围切换
- 顶部 el-date-picker(预置:今日/7天/30天/自定义)
- 切换时所有图表同时重新请求 API
- 加载状态:图表显示 loading 遮罩,KPI 卡片显示骨架屏
- 自动刷新:可选[自动刷新:30s/60s/5min]开关,默认关闭
