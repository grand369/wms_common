## 1. 制造业仓储行业分析

### 1.1 行业全景

| 维度 | 内容 |
|------|------|
| **市场规模** | 全球 WMS 市场规模（2024）约 35 亿美元，预计 2030 年突破 80 亿美元，CAGR≈15%。中国制造业 WMS 市场约 60~80 亿人民币，年增速约 20%，是全球增速最快的区域之一 |
| **市场结构** | 头部 SAP EWM / Oracle WMS / Manhattan Associates 占据大型企业市场；中小企业市场高度分散，国产化替代需求强劲 |
| **驱动力** | 供应链数字化政策（工信部"5G+工业互联网"）、制造业降本增效压力、劳动力成本上涨、精益制造推广 |
| **技术趋势** | 仓储自动化（AMR/AGV/立库）、IoT 感知、AI 需求预测、数字孪生、云原生部署、移动 PDA/手持终端普及 |

### 1.2 仓储在制造业价值链中的位置

```
供应商 → [采购] → 原材料仓 → [生产领料] → 线边仓 → [生产加工]
                                                           ↓
成品仓 ← [成品入库] ← 半成品仓 ← [工序转移] ← 制造工序
  ↓
[销售出库] → 客户
```

**价值链核心作用：**

| 环节 | 仓储价值 |
|------|----------|
| **供应端** | 缓冲采购批量与生产节拍的时间差；暂存来料待检品 |
| **制造端** | 按时按量向产线配送物料，保障生产连续性；管理在制品与半成品流转 |
| **销售端** | 成品储存与分拣发货；支撑订单履约时效 |
| **逆向物流** | 退货/返工/报废处理；废料与可回收材料管理 |

**关键 KPI 指标：**
- 库存周转率（月/年）
- 缺料率（影响生产计划达成率）
- 入库/出库准确率
- 仓库空间利用率
- 拣货效率（单/小时）
- 库存账物相符率

### 1.3 数字化转型趋势

| 阶段 | 特征 | 代表技术 |
|------|------|----------|
| **1.0 手工台账** | Excel/纸单管理，库存不透明 | — |
| **2.0 ERP 库存模块** | 财务视角的库存记录，缺乏仓内作业管控 | ERP（SAP/金蝶/用友） |
| **3.0 WMS 系统** | 仓内精细化管控，库位/批次/序列号追踪 | WMS + 条码/RFID |
| **4.0 智慧仓储** | 自动化设备集成、AI 调度、实时可视化 | AGV/AMR + WCS + WMS + IoT |
| **5.0 数字孪生** | 全要素数字映射，仿真优化 | Digital Twin + AI + Cloud |

**中国制造业当前阶段分布（估算）：**

```
1.0（手工）：~15%（小微企业）
2.0（ERP库存）：~40%（中小企业）
3.0（WMS）：~35%（中大型企业）
4.0（智慧仓储）：~9%（大型/头部企业）
5.0（数字孪生）：<1%（试点阶段）
```

**本平台目标客户主要处于 2.0→3.0 过渡阶段，部分触达 3.0→4.0 升级需求。**

## 2. 业务痛点

> **Purpose**：识别制造业仓储管理的核心矛盾，作为平台功能优先级和设计决策的输入依据。

### 2.1 核心痛点清单

| # | 痛点名称 | 具体表现 | 业务影响 | 平台设计启示 |
|---|----------|----------|----------|--------------|
| **P01** | **库存不透明** | 实物数量与系统记录不符，账物差异大；无法实时查询库位级库存 | 生产缺料、重复采购、呆滞积压 | 强制账实同步；库位级实时库存；多维度库存查询 |
| **P02** | **入库质量管控缺失** | 来料未经质检直接入库；批次不追踪；质量问题批次无法快速召回 | 质量事故扩散；追溯困难 | 质检状态管控（待检/合格/不合格）；批次/序列号全程追踪 |
| **P03** | **缺料频发** | 生产领料时发现库存不足；BOM 与实际用料偏差未预警 | 生产停线、计划延误 | 需求预测预警；安全库存设定；缺料提前预警推送 |
| **P04** | **物料配送效率低** | 按时送料到线边依赖人工经验；多产线并行时配送混乱 | 产线等料停工；配送员工负担重 | 拣货任务智能拆单；路径优化；PDA 移动作业指引 |
| **P05** | **条码/标签管理混乱** | 物料标签格式不统一；二次入库标签丢失；无法快速扫码识别 | 入出库错误；追溯断链 | 统一标签模板引擎；入库强制扫码；打印服务集成 |
| **P06** | **多仓库库存割裂** | 多工厂/多仓库之间库存互不可见；调拨流程繁琐 | 甲地积压乙地缺货；资金占用高 | 统一库存视图；跨仓调拨工作流；组织层级配置 |
| **P07** | **盘点效率低、影响生产** | 每季度停线盘点，影响生产数天；盘点数据录入慢且错误率高 | 生产损失大；盘点准确性存疑 | 周期循环盘点；PDA 扫码盘点；差异自动生成调整单 |
| **P08** | **退料/退货流程不规范** | 生产退料无审批直接入库；供应商退货流程与采购/财务脱节 | 库存虚高；财务账不清 | 退料审批工作流；退货单关联采购/销售订单；自动财务凭证 |
| **P09** | **线边仓物料积压与断料并存** | 线边仓无精确库存管控；靠人工估算补料；要么积压占地要么紧急缺料 | 现场混乱；生产效率低 | 线边仓独立库位管理；看板式补料触发；最小/最大库存控制 |
| **P10** | **委外加工物料追踪失控** | 发给外协厂商的物料数量不清；成品回收核对困难；损耗无法有效管控 | 物料损失；成本核算不准 | 委外发料/收货单；损耗率设定；委外库存独立管控 |
| **P11** | **先进先出难以执行** | 系统无法自动推荐 FIFO 发料；人工拣货按就近原则取货 | 物料过期报废；批次混用 | FIFO/FEFO 发料策略；系统推荐库位；过期预警 |
| **P12** | **系统集成断点** | WMS 与 ERP/MES 数据不同步；需手工转录；双方数据打架 | 数据不一致；人工核对耗时 | 标准接口（REST/消息队列）；集成适配层；数据一致性校验 |

### 2.2 痛点根因分析

```
管理层面：
  ├─ 流程不规范（无 SOP / SOP 未执行）
  ├─ 物料编码体系混乱
  └─ 绩效考核缺失

系统层面：
  ├─ WMS 缺失或停留在 ERP 库存模块
  ├─ 与 ERP/MES 集成断点
  └─ 移动化程度低（无 PDA）

数据层面：
  ├─ 账物不符（线下操作未回单）
  ├─ 批次/序列号不追踪
  └─ 历史数据质量差
```

## 3. 典型仓储场景

> **Purpose**：梳理制造业仓储的核心业务场景，作为功能模块设计的用例依据。

### 3.1 原材料入库

**触发条件**：采购订单到货 / 供应商主动送货  
**参与角色**：采购员、仓管员、质检员

```
采购订单 → 预到货通知（ASN）→ 到货登记（扫托盘/箱码）
  → 质检取样 → [合格] 上架入库（系统分配库位）→ 更新库存
             → [不合格] 放入不合格品区 → 退货/返工申请
```

**关键业务规则：**
- 入库数量不得超过采购订单未入库余量（可配置允许超收比例）
- 支持分批到货（一个采购单多次入库）
- 必须记录批次号、生产日期、有效期（对有效期管控物料）
- 入库后自动触发打印入库标签

**特殊场景：**
- 免检物料直接上架（按供应商评级或物料类型配置）
- 托盘整托入库 vs 拆零入库
- 口岸/海关保税仓入库

---

### 3.2 生产领料

**触发条件**：生产工单下达，生产计划员发起领料申请  
**参与角色**：生产计划员、仓管员、产线组长

```
生产工单 → 领料单生成（BOM 展开）→ 仓库接收领料任务
  → 拣货（PDA 扫码，系统推荐库位 FIFO）→ 出库核对
  → 配送到线边 → 生产确认收料 → 库存扣减
```

**关键业务规则：**
- 按工单/批次领料，支持超领（可配置超领比例）
- 支持替代料领用（BOM 替代料配置）
- 已领未用物料可退库（生产退料）
- 紧急领料走绿色通道（标记优先级）

**线边仓模式：**
- 物料先配送到线边仓，再由线边仓扫码消耗
- 线边仓库存触发补料信号（看板 Kanban）

---

### 3.3 成品入库

**触发条件**：生产工单完工，质检通过  
**参与角色**：生产班组长、质检员、成品仓管员

```
生产工单完工申报 → 成品质检 → [合格] 成品入库（扫序列号/托盘码）
  → 系统分配成品库位 → 打印成品标签 → 库存更新 → 关联工单
```

**关键业务规则：**
- 成品必须关联生产工单，实现正反向追溯
- 支持序列号/批次号管理
- 成品标签含客户标签格式（按客户配置）
- 隔离区成品待销售下单

---

### 3.4 成品发货

**触发条件**：销售订单/发货计划确认  
**参与角色**：销售内勤、仓管员、物流员

```
销售订单 → 发货计划制定 → 拣货单下发（波次拣货）
  → 拣货（PDA 扫码确认）→ 集货区合托 → 发货核对（扫码装车）
  → 打印装箱单/发货单 → 更新库存 → 生成物流跟踪单号
```

**关键业务规则：**
- 发货必须核对销售订单（防超发/错发）
- 支持按订单发货 vs 按批次发货
- 冷链/特殊物料记录运输温度要求
- 支持第三方物流（3PL）接口对接

---

### 3.5 委外加工

**触发条件**：委外加工订单下达  
**参与角色**：采购/外协员、仓管员

```
委外工单 → 发料单生成 → 从原材料/半成品仓出库（记录外协库）
  → 外协厂加工 → 外协成品/半成品回厂入库
  → 核对发出数量 vs 回收数量 → 计算损耗 → 库存更新
```

**关键业务规则：**
- 发出物料记入委外库存（实物在外但库存在系统中保留）
- 损耗率可按外协商/工序配置
- 超期未回货自动预警
- 外协成品入库触发质检流程

---

### 3.6 退货处理

#### 3.6.1 供应商退货（采购退货）

```
质检不合格 / 到货多发 → 退货申请（关联采购订单/入库单）
  → 仓库暂存退货区 → 退货出库（记录退货原因）→ 通知供应商取货
  → 更新库存 → 财务应付冲减
```

#### 3.6.2 客户退货（销售退货）

```
客户退货申请 → 生成退货单（关联销售订单）→ 退货入库
  → 质检分类（可直接上架/需返修/报废）→ 库存更新
  → 财务应收冲减
```

**关键业务规则：**
- 退货必须关联原始单据（采购/销售）
- 退货物料状态标记（待检/合格/不合格）
- 支持部分退货

---

### 3.7 线边仓管理

**场景特征**：线边仓（Line-side Warehouse）是产线附近的小型物料暂存区，旨在减少生产等待，实现 JIT 供料。

```
主仓 → 补料任务（触发条件：最小库存/Kanban 信号）→ 配送到线边仓
  → 线边仓入库 → 生产工人扫码领用/自动扣减 → 库存低于阈值 → 触发补料
```

**关键业务规则：**
- 每个线边仓绑定对应产线
- 物料设定最大/最小库存（看板参数）
- 支持按工位细分（Line → Station → Position）
- 支持消耗倒推模式（按工单消耗自动扣减，无需逐件扫码）

---

### 3.8 库间调拨

**触发条件**：库存盈余转移 / 生产调配 / 组织间调配  
**类型**：同仓库不同库区调拨、不同仓库间调拨、不同工厂间调拨

```
调拨申请（申请人）→ 审批（仓库主管/运营）→ 出库确认（源仓）
  → 在途库存记录 → 入库确认（目标仓）→ 更新两仓库存
```

**关键业务规则：**
- 跨工厂调拨需要财务跨公司记账
- 在途库存独立跟踪（防止重复分配）
- 物流方式记录（内部转运/外部物流）

---

### 3.9 周期盘点

**类型**：全盘（定期停产大盘）、循环盘点（ABC 分类分频次）、抽盘（随机抽查）

```
盘点计划制定（范围/时间/人员）→ 系统生成盘点任务 → 冻结库存（防止操作干扰）
  → PDA 扫码盘点（实物 vs 账面）→ 差异报告生成
  → 差异复盘（二次核对）→ 盘盈/盘亏调整单审批 → 库存更新
```

**关键业务规则：**
- 盲盘模式（不显示账面数量，防主观偏差）
- 盘点期间允许配置是否允许出入库操作（锁仓模式）
- 差异自动计算金额（联动成本价）
- 差异超阈值需要额外审批

---

### 3.10 其他场景

| 场景 | 说明 |
|------|------|
| **报废处理** | 过期/损坏物料报废审批 → 移至报废区 → 库存核销 |
| **库位整理（移库）** | 物料从一个库位转移到另一个库位，不改变库存量，仅更新库位 |
| **质检处理** | 抽检/全检，合格放行，不合格隔离/退货/返工 |
| **库存初始化** | 新系统上线时的期初库存导入与核对 |
| **冻结/解冻** | 因质量问题或法律原因冻结特定批次，禁止出库 |
| **拆分/合并** | 大包装拆分为小包装，或多小包装合并（换算关系管理） |
| **标签补打** | 标签损坏/丢失时重打，需审批留痕 |

## 4. 物料分类

> **Purpose**：为物料主数据设计提供分类体系基础，指导仓储特性配置策略。

### 4.1 物料分类体系

| 物料类别 | 英文 | 定义 | 仓储特性 | 特殊管控要求 |
|----------|------|------|----------|--------------|
| **原材料** | Raw Material | 尚未经过任何加工的基础材料 | 大批量、按批次管理、有效期可选 | 来料检验、供应商批次号追踪 |
| **半成品** | Work-in-Progress (WIP) | 已完成部分工序，尚未完工的中间品 | 工序标识、短暂存放、库位周转快 | 工单关联、工序批次追踪 |
| **成品** | Finished Goods | 完成所有工序、通过质检的可销售产品 | 序列号管理（高值品）、批次管理、FIFO 发货 | 客户标签格式、质量证书随行 |
| **辅料** | Auxiliary Material | 不直接构成产品但生产中消耗的材料（包装材料、夹具等） | 低值、快消、批量领用 | 定额消耗管控 |
| **备件** | Spare Parts | 设备维修用的零配件 | 低频使用、长期存放、序列号管理（关键备件） | 设备关联、寿命预警 |
| **耗材** | Consumables | 生产中持续消耗的材料（刀具、砂纸、手套等） | 高频补充、简单先进先出 | 定额管控、消耗统计 |
| **包装材料** | Packaging Material | 用于成品包装的材料（纸箱、泡沫、托盘等） | 按成品 BOM 消耗 | 成本分摊到成品 |
| **危化品** | Hazardous Material | 具有危险特性的物料（酸、碱、油漆、溶剂等） | 专用仓储区域、温湿度控制 | MSDS 随行、特殊标识、法规合规 |
| **返工品** | Rework Item | 生产不良返工处理中的物料 | 隔离存放、状态追踪 | 关联原工单、返工记录 |
| **报废品** | Scrapped Item | 不可修复的废品 | 隔离封存 | 报废审批、成本核销 |

### 4.2 物料关键属性

```
物料主数据核心属性：
├─ 基本信息：物料编码、物料名称、物料类别、规格型号、计量单位（主单位/辅单位）
├─ 仓储属性：存储条件（常温/冷藏/冷冻）、最大堆叠层数、包装规格（每箱数量）
├─ 质量属性：有效期管理（是/否）、保质期天数、批次管理（是/否）、序列号管理（是/否）
├─ 库存属性：安全库存、最小订货量、ABC 分类（A/B/C）
├─ 发料策略：FIFO/FEFO/FMFO/手动
└─ 危险品属性：危险等级、MSDS 编号（可选）
```

### 4.3 物料编码策略

**推荐编码原则：**

| 原则 | 说明 |
|------|------|
| **唯一性** | 全系统唯一，不因供应商/客户代码而变 |
| **稳定性** | 物料编码一旦分配，原则上不变更 |
| **无含义性（推荐）** | 纯流水号（如 MAT-00001234），避免分类变更导致编码重构 |
| **可含义性（可选）** | 前缀分类（如 RM-钢材-001），适合物料种类稳定的场景 |
| **物料版本管理** | 物料升版（A→B）建议新建物料，旧料标记停用 |

**编码示例（推荐流水号）：**

```
MAT-[8位流水号]
示例：MAT-00001234

辅以物料分类标签（在属性字段中维护，不编入编码）
```

## 5. 仓库分类

> **Purpose**：定义平台支持的仓库类型体系，指导仓库主数据和组织结构设计。

### 5.1 仓库类型体系

| 仓库类型 | 英文 | 功能定位 | 主要业务操作 | 特殊属性 |
|----------|------|----------|--------------|----------|
| **原材料仓** | Raw Material Warehouse | 存储采购来的原材料，等待生产领用 | 采购入库、领料出库、盘点 | 来料检验区、隔离区 |
| **半成品仓** | WIP Warehouse | 存储工序间流转的半成品 | 工序入库、工序出库、调拨 | 与 MES 工序紧密集成 |
| **成品仓** | Finished Goods Warehouse | 存储待销售的成品 | 成品入库、销售出库、盘点 | 客户专区（VMI 仓） |
| **线边仓** | Line-side Warehouse | 产线附近的小型供料缓冲区 | 主仓补料入、产线消耗出 | 绑定产线、最大/最小库存 |
| **不合格品仓** | Non-Conforming Warehouse | 隔离存放质检不合格品 | 隔离入、退货/返工出 | 物理隔离、访问限制 |
| **退货仓** | Return Warehouse | 客户退货的临时暂存区 | 退货入库、检验、再入成品/报废 | 关联退货单/质检单 |
| **委外仓** | Outsourcing Warehouse | 逻辑仓库，追踪在外协厂商处的物料 | 发料出库、回收入库 | 虚拟库（无物理位置） |
| **备件仓** | Spare Parts Warehouse | 存储设备维修备件 | 备件入库、领用出库、盘点 | 设备关联 |
| **危化品仓** | Hazardous Materials Warehouse | 存储危险化学品 | 专项入出库 | 法规合规、温湿度监控 |
| **报废区** | Scrap Area | 等待报废处理的物料暂存 | 报废入、处置出 | 审批流程、成本核销 |
| **样品仓** | Sample Warehouse | 研发/销售样品 | 样品申请领用 | 关联 PLM/研发 |
| **保税仓** | Bonded Warehouse | 进出口保税物料（外向型企业） | 进口申报入、加工转内销出 | 海关监管、单独核算 |

### 5.2 仓库层级结构

平台采用三级标准仓储层级，支持配置扩展：

```
仓库（Warehouse）
  └─ 库区（Zone / Area）
       └─ 库位（Location / Bin）
            └─ [可选] 货格/托盘位（Slot）
```

**各层级属性说明：**

| 层级 | 核心属性 | 说明 |
|------|----------|------|
| **仓库** | 仓库编码、名称、类型、所属组织（工厂/公司）、负责人、地址 | 最高层级，对应实际物理仓库 |
| **库区** | 区域编码、名称、类型（收货区/存储区/发货区/隔离区）、存储条件（常温/冷链）、最大容量 | 按功能/环境分区，便于区域管控 |
| **库位** | 库位编码（通道-排-层-列）、类型（货架位/地堆位/托盘位）、最大承重、容量单位 | 最小存储单元，条码唯一标识 |

**库位编码规则示例：**

```
格式：[仓库缩写]-[库区缩写]-[通道]-[排]-[层]-[列]
示例：RM-A-01-03-02-04
含义：原材料仓 A 区，第 1 通道，第 3 排，第 2 层，第 4 列

扫码标识：每个库位贴有条码/二维码标签
```

### 5.3 仓库组织架构（多工厂场景）

```
集团公司（Group）
  ├─ 工厂 A（Plant A）
  │    ├─ 原材料仓 A
  │    ├─ 半成品仓 A
  │    ├─ 成品仓 A
  │    └─ 线边仓 A1, A2, A3
  └─ 工厂 B（Plant B）
       ├─ 原材料仓 B
       └─ 成品仓 B

逻辑仓：
  └─ 委外仓（跨工厂共享）
```

## 6. 常见业务流程

> **Purpose**：定义平台标准业务流程，作为功能模块设计和流程引擎配置的基础。

### 6.1 入库流程

#### 6.1.1 采购入库

```
[开始]
  → 采购订单确认（ERP 同步）
  → 供应商 ASN 预报（可选）
  → 到货登记（扫托盘/箱码 或 手工输入）
  → 系统核对采购订单（数量/物料/供应商）
  → 卸货 → 暂存收货区
  → 质检取样（按质检规则：全检/抽检/免检）
  → [合格] → 系统分配上架库位（按策略：就近/分类/FIFO）
  → 仓管员按指引上架（PDA 扫码确认）
  → 打印入库标签（可选）
  → 入库单完成，更新库存
  → 通知 ERP 完成收货（接口回传）
[结束]
```

**异常流程：**
- 到货超过采购订单数量 → 超收确认流程（主管审批）
- 质检不合格 → 进入不合格品处理流程
- 物料与采购单不符 → 拒收/差异报告

#### 6.1.2 生产入库（成品/半成品）

```
[开始]
  → 生产工单完工申报（MES/生产模块）
  → 成品质检
  → [合格] → 仓管接收（扫工单/序列号/托盘码）
  → 系统分配成品库位
  → 上架确认
  → 打印成品标签
  → 更新库存，关联工单
[结束]
```

#### 6.1.3 退货入库

```
[开始]
  → 退货申请/通知（客户/供应商）
  → 生成退货入库单（关联原始销售/采购单）
  → 退货物料到达，核对退货清单
  → 扫码入库（退货区/待检区）
  → 质检分类（良品/不良品/混合）
  → 良品 → 转入正常库存
  → 不良品 → 不合格品仓 / 退供应商
  → 财务冲减
[结束]
```

---

### 6.2 出库流程

#### 6.2.1 生产领料出库

```
[开始]
  → 生产计划确认 → 生成领料单（BOM 展开）
  → 仓管接收领料任务
  → 系统推荐拣货库位（FIFO/FEFO 策略）
  → 拣货（PDA 扫码，逐件/批次确认）
  → 出库核对（数量/物料）
  → 交接产线/配送到线边仓
  → 生产确认收料（PDA 扫码）
  → 库存扣减，工单领料记录更新
[结束]
```

#### 6.2.2 销售出库

```
[开始]
  → 销售订单 / 发货计划
  → 生成拣货单（波次拣货：多单合并优化路径）
  → 拣货（PDA 扫码确认）
  → 集货区复核（扫码核对）
  → 装箱打包 → 打印装箱单 / 出库单 / 物流标签
  → 扫码装车（核对发货清单）
  → 发货确认 → 库存扣减
  → 生成物流单号，通知客户
  → 通知 ERP 完成发货
[结束]
```

#### 6.2.3 调拨出库

```
[开始]
  → 调拨申请 → 审批
  → 源仓出库（扫码确认）→ 在途库存记录
  → 物料运输
  → 目标仓入库确认（扫码）
  → 在途库存消除，目标仓库存增加
[结束]
```

---

### 6.3 库内作业

| 作业类型 | 触发条件 | 核心步骤 | 关键规则 |
|----------|----------|----------|----------|
| **移库** | 库位整合/腾出空间/库区调整 | 扫描源库位 → 扫描目标库位 → 确认移库 → 更新库位记录 | 目标库位必须有足够容量；同仓库内操作 |
| **盘点** | 计划盘点/随机抽查/系统差异触发 | 盘点任务创建 → 冻结库存 → PDA 扫码盘 → 差异确认 → 调整审批 | 盲盘模式；差异阈值报警 |
| **质检** | 入库触发/工序转移/抽样计划 | 取样 → 检测 → 结果录入 → 合格/不合格处理 | 质检结果联动库存状态 |
| **补货** | 拣货库位低于最小库存 | 系统触发补货任务 → 从存储区补至拣货区 → 确认补货 | 支持自动/手动触发 |
| **拆包/合包** | 大包拆小包 / 散件合托 | 原包装出库 → 拆分/合并操作 → 新包装入库（含标签重打） | 换算关系维护；标签追踪 |

### 6.4 库存管理

#### 6.4.1 库存初始化

```
新系统上线 → 导入期初库存数据（Excel 模板）
  → 系统验证（物料/仓库/库位合法性）
  → 差异核对 → 确认导入 → 期初库存建立
  → 冻结历史数据（不允许修改）
```

#### 6.4.2 库存调整

| 调整类型 | 触发场景 | 审批要求 |
|----------|----------|----------|
| 盘亏调整 | 盘点差异（账面多于实物） | 仓库主管审批 + 金额超阈值需财务审批 |
| 盘盈调整 | 盘点差异（实物多于账面） | 同上 |
| 报废核销 | 物料报废 | 部门主管 + 财务 |
| 入库更正 | 入库数量/物料错误更正 | 仓库主管 |

#### 6.4.3 库存预警

| 预警类型 | 触发条件 | 通知方式 |
|----------|----------|----------|
| 低于安全库存 | 当前库存 ≤ 安全库存 | 站内消息 + 邮件/短信 |
| 超过最大库存 | 当前库存 ≥ 最大库存 | 站内消息 |
| 临期预警 | 有效期距今 ≤ 预警天数 | 站内消息 + 邮件 |
| 库龄预警 | 物料入库超过 N 天未使用 | 站内消息 |
| 零库存预警 | 库存为 0 且有待处理需求 | 站内消息 + 邮件 |

#### 6.4.4 库存台账

| 台账类型 | 内容 | 用途 |
|----------|------|------|
| 实时库存总账 | 物料+仓库+数量+单价+金额 | 库存当前状态查询 |
| 库位库存账 | 物料+库位+数量+批次 | 仓内精细管理 |
| 批次库存账 | 物料+批次号+在库/已出数量+有效期 | 批次追溯 |
| 库存流水账 | 每笔操作记录（增减明细） | 审计、追溯 |
| 库存台账报表 | 月初+本期入出+月末结存 | 财务对账 |

### 6.5 任务管理

平台采用**任务中心**统一管理仓库作业任务：

```
任务类型：
├─ 入库任务（上架）
├─ 出库任务（拣货 / 出货）
├─ 移库任务
├─ 盘点任务
├─ 补货任务
├─ 质检任务
└─ 打印任务

任务生命周期：
待分配 → 已分配 → 进行中 → 待确认 → 已完成
                                  ↓
                              （异常）→ 挂起 → 处理后继续/关闭
```

**任务分配策略：**
- 手动分配（主管指定）
- 区域分配（按库区绑定人员）
- 技能分配（按资质，如叉车证）
- 负载均衡（按当前待处理任务数）

## 7. 行业差异

> **Purpose**：分析不同制造行业对 WMS 的差异化需求，指导平台配置化策略设计。

### 7.1 离散制造 vs 流程制造

| 维度 | 离散制造（Discrete Manufacturing） | 流程制造（Process Manufacturing） |
|------|------------------------------------|------------------------------------|
| **典型行业** | 汽车零部件、电子、机械装备、家电 | 化工、食品饮料、医药、油漆涂料 |
| **物料形态** | 固体、可计数（件/个/套） | 液体/粉末/气体，按重量/体积计量 |
| **BOM 结构** | 多层树状结构，工序清晰 | 配方（Recipe），可能有副产品 |
| **批次管理** | 可选，关键件追踪序列号 | 强制批次管理（FDA/GMP 合规） |
| **有效期管理** | 少数物料需要（胶水/油脂） | 普遍需要（食品/医药强制） |
| **仓储方式** | 货架存放为主，可精确到件 | 罐/桶/袋，体积计量 |
| **损耗管理** | 较少（标准用量） | 较多（混合损耗、蒸发损耗） |
| **合规要求** | 汽车 IATF 16949、电子 IPC | 食品 HACCP/SC、医药 GMP、危化品法规 |

### 7.2 主要细分行业 WMS 差异

#### 7.2.1 汽车零部件

| 特点 | 仓储需求 |
|------|----------|
| 供应商交货 JIT/VMI | 供应商寄存仓；Kanban 触发补货 |
| 序列号追溯（整车级） | 强序列号管理；正反向全程追溯 |
| 客户特定标签格式 | 客户标签模板（大众 VDA 4902、丰田 ODETTE 等） |
| 超量交货协议（Deviation） | 超收偏差管理 |
| 小批量多频次配送 | 配送排班、路线优化 |

#### 7.2.2 电子制造

| 特点 | 仓储需求 |
|------|----------|
| ESD 静电防护 | ESD 分区存储、特殊库区属性 |
| 元器件 MSD（湿度敏感） | 开封时间追踪、湿度暴露时间计算 |
| SMT 物料先进先出 | 强制 FIFO，系统锁定不符合策略的库位 |
| 线边仓超细粒度（工位级） | 工位级库存管理 |
| 高SKU数量（上万种物料） | 高性能库存查询；智能分配算法 |

#### 7.2.3 食品饮料

| 特点 | 仓储需求 |
|------|----------|
| 保质期管理（强制） | FEFO 策略；临期预警；过期冻结 |
| 食品安全追溯（SC/HACCP） | 批次全程追溯；召回功能 |
| 温链管理（冷藏/冷冻） | 库区温度属性；温度记录集成 |
| 包装损耗 | 入库验收时包装破损记录 |
| 大重量/体积物料 | 叉车操作为主；吨位/立方计量 |

#### 7.2.4 医药

| 特点 | 仓储需求 |
|------|----------|
| GMP 强制合规 | 审计日志（不可删除）；电子签名；操作授权 |
| 批次严格追溯 | 从原料到成品批次链不断 |
| 状态管控（待验/合格/不合格/召回） | 五状态库存；状态变更审批 |
| GSP 药品流通 | 温湿度监控；不同药品分区 |
| 破损/召回应急 | 快速召回功能；影响范围分析 |

#### 7.2.5 化工

| 特点 | 仓储需求 |
|------|----------|
| 危化品安全 | 危化品分类存储；相容性检查（防止混储） |
| 重量/体积计量 | 磅秤集成；罐区液位集成 |
| 安全法规合规 | 化学品登记；MSDS 随行；数量上报 |
| 危废管理 | 废物出库流程；处置追踪 |

### 7.3 平台配置化适应策略

```
通用能力（所有行业）：
  ├─ 基础入出库/移库/盘点/调拨
  ├─ 批次/序列号管理（可配置开关）
  ├─ FIFO/FEFO/FMFO 策略（可配置）
  └─ 任务/工作流/规则引擎

行业配置包（Industry Pack）：
  ├─ 汽车包：VDA/ODETTE 标签、供应商 Kanban、VMI 仓
  ├─ 电子包：MSD 管理、ESD 库区、SMT 上料规则
  ├─ 食品包：FEFO 强制、HACCP 追溯、温链集成
  ├─ 医药包：GMP 审计、五状态库存、召回管理
  └─ 化工包：危化品分类、相容性检查、磅秤集成

通过规则引擎 + 工作流引擎 + 标签引擎实现配置差异化，
无需修改核心代码。
```

## 8. 扩展性策略

> **Purpose**：定义平台长期可演进的核心架构思路，保障 5 年内不因业务增长而重构。

### 8.1 平台化核心思路

**核心命题：** 如何在满足通用性的同时，支持客户的个性化需求？

```
三层策略：
┌────────────────────────────────────────────────┐
│  层次 1：核心稳定层（Stable Core）              │
│  - 领域模型、基础业务规则、核心流程             │
│  - 设计目标：极少变更，高度稳定                 │
├────────────────────────────────────────────────┤
│  层次 2：配置化层（Configuration Layer）        │
│  - 业务规则、审批流程、字段定制、单据格式        │
│  - 设计目标：客户自主配置，无需改代码            │
├────────────────────────────────────────────────┤
│  层次 3：扩展层（Extension Layer）             │
│  - 插件/Hook、自定义字段、自定义报表            │
│  - 设计目标：深度个性化，不污染核心             │
└────────────────────────────────────────────────┘
```

### 8.2 配置化策略

**哪些通过配置解决（无需改代码）：**

| 配置类别 | 配置项示例 | 实现方式 |
|----------|----------|----------|
| **业务规则** | 是否启用批次管理、是否强制质检、超收比例、允许负库存 | 功能开关（Feature Flag）+ 规则参数 |
| **工作流** | 入库审批节点、退货审批路径、差异调整审批 | 工作流引擎（可视化配置） |
| **单据模板** | 出库单格式、发货单格式、标签格式 | 模板引擎（Freemarker/Razor） |
| **组织结构** | 仓库层级、库区分类、用户权限 | 主数据配置 |
| **发料策略** | FIFO/FEFO/FMFO/手动，按物料/仓库/库区配置 | 策略模式 + 配置表 |
| **预警规则** | 安全库存阈值、临期天数、库龄天数 | 规则引擎配置 |
| **集成参数** | ERP 接口地址、字段映射、同步频率 | 集成配置中心 |

### 8.3 插件化策略

**哪些通过插件扩展（需要代码，但不修改核心）：**

| 插件类型 | 场景示例 | 实现方式 |
|----------|----------|----------|
| **设备集成插件** | AGV 调度接口、立体库 WCS 接口、磅秤读数、温度传感器 | 设备适配器接口（Adapter Pattern） |
| **行业规则插件** | 汽车 VDA 标签生成、医药 GMP 审计日志增强、食品 HACCP 追溯链 | 业务钩子（EventHandler/Hook） |
| **外部系统插件** | 客户 EDI 对接、第三方物流 API、海关系统 | 集成适配器 |
| **报表插件** | 行业专属报表、客户定制报表 | 报表模块扩展点 |
| **算法插件** | 库位分配算法（替换默认算法）、拣货路径优化 | 策略接口 + 注入 |

**插件接入规范（ABP Module）：**
```
每个插件封装为独立 ABP 模块
├─ 依赖声明（DependsOn）
├─ 注册扩展点（覆盖接口实现）
└─ 独立配置（appsettings 扩展）
```

### 8.4 模块化策略

**当前模块边界与依赖关系：**

```
基础层（无业务依赖）：
  Barcode | Label | Print | Notification | Workflow | RuleEngine | TaskCenter

核心业务层：
  Warehouse（仓库主数据）← 被所有业务模块依赖
  Material（物料主数据）← 被所有业务模块依赖
  Inventory（库存核心）← 被入出库/调拨/盘点依赖

业务操作层（依赖核心层）：
  Inbound（入库）| Outbound（出库）| Transfer（调拨）
  CycleCount（盘点）| Production（生产）| LineSideWarehouse（线边仓）

扩展层（可选部署）：
  MES 集成 | QMS | TMS | OMS | Equipment | DigitalTwin | AI
```

**模块依赖原则：**
- 下层不依赖上层（严禁循环依赖）
- 跨模块通过领域事件/接口通信，不直接引用实现
- 每个模块可独立部署（为未来微服务化预留）

### 8.5 未来模块接入预留

| 未来模块 | 接入预留设计 |
|----------|-------------|
| **MES 集成** | 工单接口抽象（IProductionOrderService）；工序消耗事件钩子 |
| **QMS** | 质检结果事件（QualityInspectionCompletedEvent）；质检单关联扩展字段 |
| **TMS** | 出库单关联运输单接口；承运商信息字段预留 |
| **OMS** | 销售订单接口抽象（ISalesOrderService）；发货回传事件 |
| **Equipment** | 设备扫码关联入出库操作；设备状态查询接口 |
| **Digital Twin** | 库存变更事件推送（实时同步孪生体）；库位状态流 |
| **AI 预测** | 库存快照定时推送；消耗历史数据接口；预测建议接收接口 |

**事件总线设计（DomainEvent）：**
```
关键领域事件（供未来模块订阅）：
├─ InventoryChangedEvent（库存变更）
├─ InboundCompletedEvent（入库完成）
├─ OutboundCompletedEvent（出库完成）
├─ TransferCompletedEvent（调拨完成）
├─ CycleCountAdjustedEvent（盘点调整）
├─ MaterialConsumedEvent（物料消耗）
└─ WarehouseTaskStatusChangedEvent（任务状态变更）
```
